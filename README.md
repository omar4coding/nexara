1-Nexara 🌐

A three-sided marketplace platform connecting shoppers, sellers, and factories/suppliers.

## What is Nexara?
Nexara allows anyone to buy products, start an online store, or find verified factory suppliers — all in one platform. No unnecessary middlemen.

2- Tech Stack
- Frontend: Next.js + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Images: Cloudinary
- Auth: JWT

3- Features (in progress)
- 🛍️ Shoppers can browse and buy products
- 🏪 Sellers can create stores and list products  
- 🏭 Factory matchmaking — find real suppliers directly

4- Status
🚧 Currently in development
